How it works

Security you can
understand

01
Generate a room code
A cryptographically random 24-character code is generated. Share it securely with your contacts.
02
Key derivation
PBKDF2 runs 300,000 iterations to turn your code into a 256-bit AES key. Brute force takes years.
03
P2P connection
WebRTC connects peers directly. Room ID is derived from SHA-256 of the code — no central registry.
04
Encrypted exchange
Every message is encrypted with a fresh random IV. AES-GCM authentication detects any tampering.

Security Audit

Every attack vector
accounted for

XSS Prevention
All user data rendered via textContent and DOM methods. Zero innerHTML with user input.
Content Security Policy
CSP header blocks injected scripts, iframing, and unauthorized resource loading.
Input Sanitization
Username strips non-alphanumeric chars. Messages capped at 2000 chars. Images limited to 5MB.
Unique Salt Per Room
PBKDF2 salt derived from the room code itself — prevents rainbow table attacks across rooms.
Authenticated Encryption
AES-GCM mode detects any tampering with ciphertext. Modified messages fail decryption entirely.

FAQ

Common questions

Is SecretRoom really free?

Yes, completely free. No account, no subscription, no hidden fees. Open the app and start chatting instantly.

How secure is SecretRoom?

SecretRoom uses AES-GCM 256-bit end-to-end encryption with PBKDF2 key derivation at 300,000 iterations. Messages are encrypted on your device — only people with the room code can decrypt them.

Does SecretRoom store my messages?

No. Messages travel peer-to-peer via WebRTC directly between users. There is no server in the middle. Nothing is stored, logged, or retained anywhere.

Do I need to create an account?

No account required. Enter a name, generate a room code, share it with your contact, and start chatting in seconds.

What devices does SecretRoom support?

SecretRoom works on any modern browser — Chrome, Firefox, Safari, and Edge — on desktop, Android, and iPhone. No app download needed.

What happens when I close the tab?

All messages are permanently gone. Since nothing is stored on any server, closing the tab ends the session completely. This is by design — maximum privacy.
